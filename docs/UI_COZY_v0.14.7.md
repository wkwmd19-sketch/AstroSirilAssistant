# v0.14.7 Astro Cozy Dark UI

## Goal

Keep the proven v0.14.6 processing behavior unchanged while reducing the rigid developer-tool feel.

## Visual changes

- Warm navy/charcoal backgrounds instead of colder graphite.
- Warm off-white primary text and softer muted labels.
- Low-saturation sky-blue accent, sage-green success and muted-red stop colors.
- Borderless card sections with larger internal padding.
- Larger button and field padding for a softer capsule-like feel.
- More vertical breathing room between major sections.
- Thin, low-contrast progress treatment.
- Same visual language in `gui.py` and `sequence_gui.py`.

## Stability policy

No processing order, Siril/SyQon command, Safe-Band behavior, project schema, or Final Export logic is intentionally changed in this release. Tk/ttk remains the UI toolkit.
