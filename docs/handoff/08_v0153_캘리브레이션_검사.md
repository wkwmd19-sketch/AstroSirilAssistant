# v0.15.3 새 채팅용 추가 결정

- 0.15.2 사용자 검증: CR3 이미지 분석 및 프로젝트 생성까지 완료했다는 화면 증거가 있음.
- 요청: 프로젝트 생성 뒤 표시되지만 GUI 연결이 없었던 `CHECK_CALIBRATION_FRAMES` 단계를 구현.
- 0.15.3: 프로젝트 내 Dark·Bias·Flat·Dark-flat 파일/폴더 등록, FITS·카메라 RAW 검사, ISO/Gain·노출·해상도 등 비교, 사용자 결과 검토, 승인한 단일 Light에 한해 보정 없이 Gradient로 전환.
- 중요: **캘리브레이션을 실제로 적용하는 기능은 아직 미구현.** 사용자 확인 없는 자동 적용과 정규화된 RGB FITS에 CFA RAW Master를 직접 적용하는 처리는 금지.
- 검사 결과: `project.yaml`의 `calibration.checked`, `frames`, `compatibility`, `resolution`; JSON 보고서: `logs/calibration_report.json`.
- 신규 상태/작업: `CALIBRATION_CHECKED` / `REVIEW_CALIBRATION_FRAMES`, 건너뛰기 승인: `CALIBRATION_SKIPPED`.
- 검사 결과가 있는 상태에서 프레임을 추가하면 `calibration.checked=False`로 만료 및 재검사 필요.
- 검증: Python 구문·의존성 독립/Stubbed 테스트·모의 프로젝트 흐름. 실제 Astropy FITS 입출력/Windows·Siril·Canon CR3 프레임 검증은 남음.
- GitHub는 아직 커밋/푸시하지 않음. 배포는 전체 v0.15.3 ZIP.

세부 동작/검증 순서는 `docs/CALIBRATION_CHECK_v0.15.3.md`를 참조.
