- **[확정/요구]**: 사용자가 선택한 정책 또는 개발을 진행하며 명시적으로 채택한 요구사항.
- **[구현]**: 기준 소스에서 코드·설정·UI 동작이 확인되는 항목. 실제 사용 환경에서 성공했다는 뜻은 아님.
- **[실사용 확인]**: 기존 릴리스 문서 또는 사용자가 제공한 실행 기록에 성공이 명시된 범위.
- **[설계/예약]**: 스키마·프로파일·설명은 존재하지만 전용 처리 엔진 완료를 의미하지 않음.
- **[미검증/조사]**: 재현·테스트가 필요하거나 원인이 추정에 머물러 있는 항목.

## 최우선 충돌 해결 원칙

1. 같은 주제의 이전 설계와 최신 구현이 다르면 **최신으로 확정된 결정과 v0.15.1 코드**를 기준으로 삼습니다.
2. 특히 프로젝트 폴더는 최신 `Auto_<대상>_<날짜>[_NN]`이고, 최종 결과 **파일명**은 `<대상>_final_Auto.*`입니다. 구형 `<대상>_<날짜>_Auto` 프로젝트를 읽는 기능은 유지합니다.
3. `docs/NEXT_STEPS.md`는 초기에 작성된 로드맵이므로 이미 구현된 항목도 포함합니다. 현재의 미완료 목록으로 그대로 복사하지 않습니다.
4. 버전 번호·완료 여부·Windows 실사용 검증 여부를 섞지 않습니다. 테스트를 통과하지 않은 변경은 완료로 표시하지 않습니다.
5. 사용자가 요청한 대로 **Git 커밋/푸시는 별도 요청 전까지 보류**합니다. 작업 중에는 다운로드 가능한 전체 ZIP으로 전달합니다.

> 이 자료는 이전 채팅을 아카이브하기 전에 새 채팅으로 이관하기 위한 문서입니다. 기존 채팅의 모든 문장을 복제한 기록은 아니므로, 이 자료에 없는 새 요구사항은 추측해 확정하지 않습니다.
