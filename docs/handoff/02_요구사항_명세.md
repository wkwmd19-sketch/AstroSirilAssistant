# 요구사항 명세 — 2026-09-30, v0.15.1 기준

이 문서는 사용자 결정과 기준 소스의 동작 계약을 분리합니다. `[구현]`은 소스 존재를 뜻하며, 전체 기능의 실사용 검증을 보장하지 않습니다.

## A. 제품·운영 정책

| ID | 상태 | 요구사항 / 수용 기준 |
|---|---|---|
| PRD-01 | [확정/요구] | Siril 기반 반자동 천체사진 프로그램. 각 단계에서 현재 상태·다음 작업·설명·추천·주의·완료 기준을 제시한다. |
| PRD-02 | [확정/요구] | 위험한 처리(추가 GHS, 중복 Calibration, 비싼 AI 실제 적용)는 모호한 추측으로 자동 실행하지 않고 사용자 선택 또는 확인을 받는다. |
| PRD-03 | [확정/요구] | 추천값은 대상 종류·특징·이미지 통계를 이용한 **시작값**. `추천 다시 계산` / `추천값 적용` / `천체 특징 수정`으로 사용자가 수정한다. |
| PRD-04 | [확정/요구] | 기존 프로젝트 상태·이미 생성된 결과와 원본을 보존하며, 신규 기능을 넣어도 v0.6~v0.13 등 이전 진행 상태를 함부로 되돌리지 않는다. |
| PRD-05 | [확정/요구] | 다운로드 편의상 전체 ZIP 제공을 우선한다. 코드와 버전 정리가 끝나기 전에는 Git 커밋/푸시를 보류한다. |

## B. 입력·프로젝트

| ID | 상태 | 요구사항 / 수용 기준 |
|---|---|---|
| IN-01 | [구현] | 단일 이미지 지원: `.fits`, `.fit`, `.fts`, `.fits.fz`, `.cr2`, `.cr3`, `.nef`, `.arw`, `.dng`, `.raf`, `.orf`, `.rw2`, `.pef`, `.tif`, `.tiff`, `.png`, `.jpg`, `.jpeg`. |
| IN-02 | [확정/요구][구현] | `이미지` 경로는 읽기 전용 선택 필드, `저장 위치`도 폴더 선택 기반. `이미지 분석` 성공 후에만 `프로젝트 생성`을 활성화한다. 생성 시 분석을 중복 수행하지 않는다. |
| IN-03 | [확정/요구][구현] | `OBJECT`와 `DATE-OBS`/`DATE`를 우선 활용해 대상명·촬영일 자동 입력. 알려진 대상은 Registry 기준 종류 자동 분류, 미확인 대상은 `기타 / 직접입력`. 사용자 수정이 최종 우선. |
| IN-04 | [확정/요구][구현] | 입력 정보 카드에서 해상도·비트 깊이·카메라/장비·노출·Gain/ISO·필터·분석 후 Linearity 등을 가능한 범위에서 보여준다. 없는 메타데이터를 임의로 채우지 않는다. |
| IN-05 | [구현] | 선택 원본을 `input/original`로 무변경 복사. 실제 후처리는 `input/normalized/`의 작업용 FITS로 진행. 포맷·변환 방식 등은 `input/metadata/source_metadata.json` 및 `project.yaml`에 기록. |
| IN-06 | [구현][미검증/조사] | RAW는 격리된 한 파일 임시 폴더로 복사 → Siril 내부 `cd` → `convertraw ... -debayer` → FITS load/save. RAW 결과가 정확히 하나인지 검증. v0.15.1은 실제 RAW 변환까지 성공했지만 이미지 분석 전체 완료는 미검증. |
| IN-07 | [확정/요구][구현] | Debayer 여부가 불확실한 generic loader fallback을 사용하지 않는다. JPEG는 Non-linear·손실 입력으로, PNG/TIFF는 모호하면 확인 대상. |
| IN-08 | [확정/요구][구현] | 신규 폴더명 `Auto_<대상>_<YYYY-MM-DD>[_NN]`; 중복 시 `기존 프로젝트 열기` / `새 프로젝트 만들기` / `취소`. 기존 프로젝트 덮어쓰기 금지 및 예전 `<대상>_<YYYY-MM-DD>_Auto` 열기 지원. |
| IN-09 | [구현] | `저작권 (선택)`은 `project.yaml` 보관 후 Final FITS의 `COPYRGHT` 헤더에 기록. TIFF/PNG에 자동 삽입하거나 이미지에 워터마크를 찍지 않는다. |

| CAL-03 | [구현] | 딥스카이 FITS 시퀀스는 `계획 생성 → 확인 → 승인 후 실제 실행` 뒤 Master/Calibration/Registration/Stack 단계를 실행한다. 품질지표를 근거로 한 자동 프레임 제외는 강제하지 않는다. |

| PRO-02 | [구현] | SPCC는 Linear·Plate Solved 이미지에서 실행, Siril 명령/카탈로그 등의 조건을 확인. |
| PRO-03 | [확정/요구][구현] | Restoration의 기본값은 SyQon Parallax Nano, Denoise 기본값은 SyQon Prism Mini. Siril RL/Native는 폴백으로 유지. 설치된 SyQon 스크립트를 참조하며 모델 배포는 하지 않는다. |
| PRO-04 | [확정/요구][구현] | Parallax `빠른 미리보기`는 기본 중앙 1536×1536 **원본 픽셀 스케일 Crop**. `전체 처리 + 결과 확인` 뒤 일치하는 후보에 대해 `결과 승인` 시 재계산 없이 승격. |
| PRO-05 | [구현][실사용 확인] | v0.14.5의 SyQon FULL Safe-Band는 큰 이미지에서 겹침 band를 동일 픽셀 스케일로 처리, feather 결합 후 원본 크기 Linear FITS로 복원. 전체 성공/설정별 정확도는 입력·환경에 따라 재검증. |
| PRO-06 | [확정/요구][구현] | 화면 표시용 AutoStretch는 Linear 작업 FITS를 바꾸지 않는다. Before/After에는 Before에서 계산한 동일한 표시 Stretch를 적용한다. |
| PRO-07 | [확정/요구][구현] | 최초 GHS로 Linear → Non-linear 전환, 추가 Pass는 명시적 선택·개별 결과 저장. GHS 결과 미리보기에 중복 AutoStretch 금지. |
| PRO-08 | [구현] | StarNet은 Starless/Stars 분리, 각각 별도 처리 후 Pixel Math 재합성. 값이 같은 승인 후보는 무거운 AI/연산을 불필요하게 반복하지 않는다. |
| EXP-01 | [확정/요구][구현] | 최종 결과는 `<대상>_final_Auto` 규칙. 출력 선택에 따라 FITS(32-bit), TIFF/PNG(16-bit), 표시용 JPEG. 파일 생성 실재 확인 후에만 `EXPORTED`. 최종 미리보기 선행. |

## E. 예약/미완료 경계

- **[설계/예약]** 은하수의 고정/추적 촬영별 지상·하늘 처리, 별 일주 시퀀스 품질·간격 검사와 Lighten/Max 합성, 혜성 전용 정렬, 모자이크 결합, 달/행성 SER/AVI 전용 처리는 설계 파일과 일부 프로파일이 있어도 전체 완성을 의미하지 않는다.
- **[설계/예약]** 다중 세션/필터 그룹/공유 Master Library/품질지표/Dither·Meridian Flip 처리 항목은 코드·설정별 구현 수준을 확인한 뒤 작업 항목으로 관리한다.
- **[미검증/조사]** 0.15.1 Canon CR3 입력 이미지 분석 실패, 메타데이터 통계 키 이상, 로그의 16-bit vs 문서화된 32-bit 정규화 불일치에 대한 재검증이 필요하다.
