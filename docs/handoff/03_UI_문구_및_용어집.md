# UI 문구·용어집 — 사용 및 유지 기준

아래는 **v0.15.1 코드에서 확인된 실제 문구**와 이후 문구를 수정할 때 일관되게 사용할 용어입니다. `정의`는 문구의 사용자 의미이며, 단순 번역 관계는 아닙니다.

## A. 프로젝트 시작 / 입력 필드

| 목적 | 기준 UI 문구 | 규칙 |
|---|---|---|
| 파일 선택 필드 | `이미지` | 과거 `입력 FITS` 대신 다중 형식을 아우르는 표현. 선택 경로는 읽기 전용. |
| 대상 직접 입력 안내 | `천체 명칭을 입력해주세요.` | 헤더에서 대상명을 찾지 못한 경우 placeholder. |
| 미분류 대상 | `기타 / 직접입력` | 자동 분류 근거가 충분하지 않을 때. |
| 폴더 지정 | `저장 위치` | 읽기 전용 경로 + 폴더 선택. |
| 선택 메타데이터 | `저작권 (선택)` | 프로젝트/Final FITS 헤더용, 워터마크 아님. |
| 사전 검사 | `Siril 연결 확인` | 경로·버전 확인 결과를 팝업 안내. |
| 모델/스크립트 확인 | `SyQon 설치 확인` | 설치된 Parallax/Prism 가용성 확인. |
| 분석 | `이미지 분석` | 입력 분류·필요 시 정규화·메타데이터/픽셀 분석. |
| 생성 | `프로젝트 생성` | 분석 성공 후 활성화. 분석 반복 실행 금지. |
| 이어서 작업 | `기존 프로젝트 열기` | 이전 상태와 작업 결과를 이어 받음. |
| 동일 대상/날짜 중복 | `기존 프로젝트 열기` / `새 프로젝트 만들기` / `취소` | 의미 없는 Yes/No/Cancel 대신 명시적인 행동. |

## B. 공통 상태·설명

| 기준 UI 문구 | 의미/표시 정책 |
|---|---|
| `현재 단계 : <한 줄 설명>` | 상단 요약의 주된 설명 영역. 중복 문장 최소화. |
| `다음 작업 : <단계명>` | 다음 단계명만 표시. 자세한 경고·기본값을 계속 반복하지 않음. |
| `현재 단계 설정` | 단계별 파라미터/동작 카드의 명칭. |
| `상태` + 상태값 | 상태 제목과 실제 값을 두 줄로 구분. |
| `MM:SS` | 경과시간 표시. `경과`라는 단어를 반복하여 앞에 붙이지 않음. |
| `▼ 상세 로그 보기` / `▲ 상세 로그 숨기기` | 기본 접힘 상태와 펼침 제어. |
| `로그 복사` | 사용자에게 진단 정보를 복사할 수 있게 제공. |
| `중단` | 동작 중 접근 가능한 중단 버튼. 파괴적 삭제 버튼이 아님. |
| `이미지 분석 완료 · 프로젝트를 생성할 수 있습니다.` | 분석 성공 이후 프로젝트 생성 활성화 안내. |
| `이미지 분석 필요` / `현재 이미지를 먼저 분석하세요.` | 생성 전 분석 요구 메시지. |

## C. Restoration/Parallax 및 공통 작업 동사

| 기준 UI 문구 | 의미 |
|---|---|
| `빠른 미리보기` | 기본 1536×1536 원본 픽셀 스케일 Crop으로 설정값을 비교. 정식 결과로 승인하지 않음. |
| `전체 처리 + 결과 확인` | 원본 전체 범위를 처리한 후보를 만든 후 확인. 큰 입력에는 Safe-Band 가능. |
| `결과 승인` | 현재 설정과 일치하는 FULL 후보를 working 결과로 승격. 후보를 다시 계산하지 않음. |
| `빠른 미리보기는 값 비교용입니다.` | 빠른 Crop만 실행한 상태에서 승인하려 할 때. |
| `현재 설정과 동일한 값으로 [전체 처리 + 결과 확인]을 완료한 뒤 승인하세요.` | FULL 결과 없거나 설정이 달라진 경우. |
| `추천 다시 계산` / `추천값 적용` / `천체 특징 수정` | 추천값이 결정이 아닌 출발점임을 반영. |
| `미리보기` / `승인 후 적용` / `건너뛰기` | 다른 단계에 사용되는 단계형 동작. Restoration의 `결과 승인`과 혼용할 때 후보 의미를 일치시킬 것. |
| `PREVIEW / RUN / EDIT / SKIP` | 상태 엔진/로그의 내부 선택 ID. 사용자 표시 문구와 구별. |
| `Before · SPCC` / `After · Parallax` | 같은 Stretch로 나란히 비교하는 표시용 결과. |
| `최종 결과 폴더 열기` | Export 성공·실제 결과 파일 존재 시에만 제공. |

## D. 용어 정의

| 용어/표기 | 정의 및 사용 시 주의 |
|---|---|
| `Light` | 촬영 대상의 원본/처리 입력 프레임. 단일 Light와 시퀀스 및 스택을 혼동하지 않는다. |
| `Dark` | 같은 조건의 암전류/핫픽셀 성분 보정용 프레임. |
| `Bias` | 매우 짧은 노출의 읽기 오프셋 성분 보정용 프레임. |
| `Flat` | 비네팅·먼지·광학계 조도 불균일 보정용 프레임. |
| `Dark-flat` | Flat과 같은 노출 조건으로 촬영한 암프레임. Bias와 무조건 동시 사용하지 않는다. |
| `Master` | Calibration 프레임을 합성한 기준 프레임. |
| `CFA` | Bayer 등의 단색 센서 색 필터 배열. RAW 시퀀스는 일반적으로 보정 후 Debayer. |
| `Debayer / Demosaic` | CFA 단일 채널에서 컬러 RGB 영상을 복원하는 과정. 입력 변환의 성공 조건으로 명시. |
| `Calibration` | Dark/Bias/Flat 등을 이용한 센서·광학계 체계오차 보정. |
| `Registration` | 프레임 사이의 별 위치 등을 정렬. 별 일주사진은 일반 별 정렬 대상이 아님. |
| `Stack` | 여러 프레임을 합성해 신호대잡음비 등을 개선하는 처리. |
| `Linear` | 실제 Stretch가 아직 적용되지 않은 처리 상태. 표시용 AutoStretch와 구별. |
| `Non-linear` | 실제 Stretch 등으로 픽셀 신호 관계가 변환된 상태. |
| `AutoStretch` | 화면/미리보기 가시성을 위한 표시 변환. Linear FITS를 바꾸지 않는 경우를 명시. |
| `Gradient` | 광공해·배경 기울기 등 배경 불균일 성분의 제거 단계. |
| `SPCC` | Spectrophotometric Color Calibration. Linear·Plate Solve 요건 확인. |
| `Restoration / Deblur` | 별 수차·구조 복원 단계; 기본 SyQon Parallax Nano, 폴백 Siril RL. |
| `Denoise` | 노이즈 감소 단계; 기본 SyQon Prism Mini, 폴백 Siril Native. |
| `Safe-Band` | 큰 FULL 이미지를 겹치는 원본 픽셀 스케일 band로 처리하고 결합하는 호환 경로. |
| `GHS` | Generalised/Generalized Hyperbolic Stretch. 첫 Pass 뒤 Non-linear 상태 전환. |
| `StarNet` | 별/배경 분리 단계. `Starless`는 별이 제거된 레이어, `Stars`는 별 레이어. |
| `Recombine` | 분리한 별과 배경을 Pixel Math로 재합성. |
| `Candidate` | 미리보기/전체 처리로 만든 승인 전 임시 결과. 설정과 일치하지 않으면 재사용 불가. |
| `Final / Export` | 검토한 최종 작업 이미지를 지정한 형식으로 저장·검증. |
| `Working FITS` | 프로젝트 내부에서 이어서 작업하는 FITS. Export 파일과 구분. |
| `Gain` / `ISO` | 센서·촬영 정보. FITS에 GAIN 대신 ISOSPEED만 있으면 ISO로 표기. |

## E. 메시지 정책

- 실패·취소를 성공으로 표시하지 않는다. Siril 프로세스의 정상 종료뿐 아니라 **예상 출력 파일이 실제 존재하는지** 확인한다.
- 실행 중 상세 로그에 주요 진행을 표시하고, 시간이 오래 걸린다고 임의 퍼센트를 꾸며내지 않는다.
- 오류 시 로그를 자동으로 펼치고 원문 오류와 사용자용 간결한 설명을 함께 제공한다.
- `RAW`는 파일 형식·디코딩 개념으로 사용하고, `RAW_UNCALIBRATED`는 **보정 여부 상태 ID**이므로 구분한다.
- `32-bit 작업 모드`와 **실제 FITS `BITPIX=-32` 저장**을 구분한다. v0.15.1 실제 CR3 로그는 `BITPIX=16`이므로 검증 없이 `32-bit 저장 완료` 문구로 확정하지 않는다.
