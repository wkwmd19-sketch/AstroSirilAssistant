# UI Status / Progress / Log UX v0.6.0

## 실행 중 상태
미리보기/실제 적용이 시작되면:

- `● 실행 중: 작업명`
- Indeterminate Progress Bar
- `경과 MM:SS`
- 상세 로그에 `▶ 실행 시작: 작업명`

을 표시합니다.

정확한 퍼센트를 Siril에서 안정적으로 얻기 어려운 단계는 가짜 %를 표시하지 않습니다.

## 실행 중 잠금
처리 중에는 주요 입력/적용 버튼을 잠시 비활성화합니다.
상세 로그 보기/복사는 계속 사용할 수 있습니다.

## 완료
실제 `승인 후 적용` 작업이 성공하면 완료 팝업을 표시합니다.

미리보기는 팝업을 띄우지 않고:
- 상태 완료
- JPEG 자동 열기
로 처리합니다.

## 오류
- Progress Bar 중지
- 오류 상태 표시
- 상세 로그 자동 펼침
- 오류 팝업 표시

## 로그
기본은 접힘 상태입니다.

- `▼ 상세 로그 보기`
- `▲ 상세 로그 숨기기`
- `로그 복사`
